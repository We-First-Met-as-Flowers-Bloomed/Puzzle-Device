## 演示流程

1. 给装置上电并等待初始化。
2. 在视觉模块上按下启动键。
3. AI视觉模块分析碎片当前位置，求解目标位置与旋转角。
4. STM32 控制四轴和电磁铁依次完成吸取、移动、旋转和放置。
5. 相同过程循环执行，直到所有碎片拼接完成。

演示所用装置针对题目规定的材料、尺寸、数量和工作区条件设计。超出题目范围的碎片、摆放方式或光照条件未作为该原型的能力保证。
